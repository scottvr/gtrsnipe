> **Written for gtrsnipe v0.2**, whose mapper chose each note's position greedily. Since v0.3.0:
> - the default mapper optimizes the whole piece, so the tab below may come out differently
>   today; add `--optimizer greedy` for the v0.2 mapper;
> - Basic-Pitch has been removed, and librosa's pYIN, described below, is the only pitch detector;
> - audio input needs `pip install 'gtrsnipe[audio]'`, and `--stem-track` (Demucs) also needs
>   `pip install 'gtrsnipe[separation]'`.

SO the machine learning model I started out with turns out to be *too* good at detecting pitch bends and small nuances in timings etc so i was unable to get any usable MIDI to transcribe to TAB from [Basic-Pitch](https://github.com/spotify/basic-pitch). Instead, I rolled my own pitch detection (well, I rolled [librosa's](https://librosa.org/doc/latest/index.html) implementation of [pYIN](https://ieeexplore.ieee.org/document/6853678) into [gtrsnipe](https://github.com/scottvr/gtrsnipe) ) the old-fashioned way to reasonable success. 

The trade-off is that this average pitch detection is by virtue monophonic so I was limited to testing on bass or some other instrument part not likely to be played polyphonically (or be noticed that it was not.) I needed a good bass-line for gtrsnipe to try to transcribe from the actual audio so I went to YouTube and found a clip of the [opening theme song to Barney Miller](https://www.youtube.com/watch?v=II71tmVsKrE). I converted the youtube video to an mp3 with ffmpeg, then fed the mp3 to [demucs_6s](https://github.com/facebookresearch/demucs) to isolate the bass part into its own WAV file. I read this WAV with librosa.pYIN for frequency estimation on it and output the resulting pitches to MIDI notes, which were then consumed by the gtrsnipe fretboard mapper algorithm to give us this totally decent tab for the bass line to Barney Miller.

> **Note (v0.6.10):** the command in the tab's header below no longer runs as shown:
> `--pre-quantize` is gone, and pre-quantizing is on by default (`--no-pre-quantize` turns it
> off). Today's command is the same without it:
>
> ```
> gtrsnipe -i barney_miller.mp3 --pitch-engine librosa -o barney_miller-bass.tab --bass --stem-track bass --dedupe -y --quantization-resolution 0.0625 --max-line-width 80 --sweet-spot-high 5 --fretted-open-penalty 0 --string-switch-penalty 0
> ```
